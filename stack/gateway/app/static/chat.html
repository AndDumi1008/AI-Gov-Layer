every message goes through the governance gateway 
Connect as a seeded user, pick a classification and a model, and ask. Each answer shows the gateway's decision, the model and region that served it, the cost, and a link to the audit event.

The model has no access to the gateway's data: it cannot list your events or budgets. Ask the gateway directly with slash commands: /events, /why <event id>, /models, /repos, /budget, /whoami, /help.
