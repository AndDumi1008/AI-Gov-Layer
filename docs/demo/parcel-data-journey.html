Immutable ledger

Each event is SHA-256 hashed together with the previous hash and written to WORM storage. The ledger holds hashes of personal data, never the data itself, so erasure at stage 9 leaves the chain intact.

Roles and masks follow the AI Governance Layer documents: classification ceilings, DLP redaction before any model call, EU-pinned endpoints, reserve/settle budgeting, and a hash-chained audit store separate from erasable content. Relay numbers expire with the courier's assignment. Pseudonyms are salted hashes kept in a key store the analytics role cannot read.
